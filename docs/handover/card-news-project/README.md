# 카드뉴스 제작 스킬 전달 패키지 (Claude Code 없이 사용)

받는 분이 **claude.ai 프로젝트**에서 카드뉴스를 만들 수 있게 정리한 자료입니다.

## 구성

| 파일 | 용도 |
|---|---|
| `워크플로우.md` | 처음부터 끝까지 따라 하는 순서(한 번만 하는 설정 + 주간 사이클 + 막힐 때) |
| `프로젝트_지침.md` | claude.ai 프로젝트의 "지침" 칸에 붙여 넣을 내용 |
| `card-news-production/SKILL.md` | 카드뉴스 제작 스킬 본문(규칙 전체) |
| `card-news-production/references/브랜드설정.md` | **받는 분이 채워야 하는 빈 양식**(학원명·색상·연락처 등) |
| `card-news-production/references/브랜드설정_작성예시_나인플러스.md` | 채우는 방법 예시 |
| `card-news-production/references/예시_스토리보드.md` | 실제 발행한 카드뉴스 스토리보드 예시 |
| `card-news-production/references/이미지프롬프트_양식.md` | 이미지 생성 프롬프트 양식 |
| `card-news-production.zip` | 스킬 폴더를 압축한 파일(claude.ai 스킬 업로드용) |

## 사용 방법 (두 가지 중 하나)

**A. 프로젝트 지식으로 쓰기 (모든 요금제에서 가능, 권장)**
1. claude.ai → 프로젝트 → 새 프로젝트 만들기
2. `프로젝트_지침.md`의 내용을 프로젝트 지침에 붙여 넣기
3. `card-news-production` 폴더 안 파일 5개(SKILL.md + references 4개)를 프로젝트 지식에 업로드
4. `브랜드설정.md`를 채워 다시 업로드

**B. 스킬로 쓰기 (스킬 기능이 있는 요금제)**
1. claude.ai 설정의 스킬(Skills) 메뉴에서 `card-news-production.zip` 업로드
2. 스킬을 켠 뒤 프로젝트 지침(`프로젝트_지침.md`)은 그대로 사용
3. 스킬 폴더 안 `references/브랜드설정.md`를 채운 뒤 zip을 다시 만들어 올리거나, 채운 내용을 프로젝트 지식에 따로 업로드

스킬 메뉴의 위치와 지원 요금제는 Anthropic이 바꿀 수 있으니, 메뉴가 없으면 A 방법을 쓰면 됩니다.

## 전달 전에 확인한 것

- 이 패키지에는 API 키·토큰·계정 정보가 없습니다.
- 학원 고유 정보(등록번호·연락처 등)는 `브랜드설정_작성예시_나인플러스.md`에도 실제 값을 넣지 않았습니다. 받는 분은 자기 정보로 채우면 됩니다.
- `예시_스토리보드.md`는 이미 공개된 블로그 글을 바탕으로 한 예시이며, 받는 분의 주제·수치로 바꿔 써야 합니다.
