## 작성 예시 (표지)
```
한국 일상 웹툰 스타일 디지털 일러스트, 미국식 카툰·디즈니풍 아님, 얇고 정교한 선화와 부드러운 셀쉐이딩,
자연스러운 인물 비율, 남색(#10203f)·골드(#F0B93D) 2톤 배경 + 은은한 하프톤. 화면 안에 글자·숫자·로고 없음.
남중생 — 남색 맨투맨(사복). 장면: 저녁 책상 앞에서 한 손으로 시험지 한 장(글자와 점수는 읽을 수 없는 흐린 선,
큰 동그라미 표시 하나)을 들고 고개를 갸웃하며 의아해하는 표정. 책상 위에 노트와 연필, 따뜻한 스탠드 불빛,
남색 창밖 저녁 하늘. 인물은 화면 상단~중단에 배치하고 화면 하단 35%는 단순한 책상 면. 3:4 세로.
```

## 생성 후 확인
- 인물 얼굴·손가락이 이상하지 않은가? 앞 컷과 같은 인물로 보이는가?
- 화면 안에 글자·숫자·로고가 읽히지 않는가?
- 우하단 생성도구 워터마크는 합성 단계에서 가린다(그라데이션·크롭).
- 인물이 프레임 가장자리에 붙어 있지 않은가(4:5 크롭 때 잘림)?
