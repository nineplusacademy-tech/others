# 카드뉴스 제작 스킬

블로그 글 한 편에서 카드뉴스 9장을 파생 제작하는 방법이다. 이 스킬은 **글과 지시서를 만드는 단계**까지 맡는다.
이미지 생성(구글 플로우·Gemini 등)과 글자 합성(캔바·파워포인트 등)은 사람이 외부 도구에서 하고,
그 결과물을 가져오면 다시 이 스킬로 점검한다.

## 0. 시작 전 반드시 할 일

1. `references/브랜드설정.md`를 읽는다. 파일이 없거나 `[여기에 입력]` 칸이 남아 있으면, **제작을 시작하지 말고**
   비어 있는 항목을 사용자에게 한 번에 묶어서 질문해 채운다(학원/브랜드명, 타겟, 색상, 연락처, 해시태그, 법정 고시사항, CTA 방식).
2. 브랜드설정에 없는 연락처·URL·수치·학교명·등록번호를 **절대 지어내지 않는다.** 모르면 `[확인 필요]`로 남긴다.
3. 이번 카드뉴스의 **출처 원고**를 받는다. 원고 없이 주제만 있으면 먼저 짧은 원고(소제목·핵심 문장·수치·출처)부터 쓰고 승인받는다.
   카드뉴스는 항상 원고에서 파생한다 — 원고에 없는 수치·주장을 카드에 새로 넣지 않는다.
4. 타겟(누가 보는가)을 한 줄로 다시 확인하고 그 전제로 톤·소재·해시태그를 정한다.

## 1. 진행 순서 (한 단계씩, 단계마다 확인받는다)

| 단계 | 산출물 | 확인 |
|---|---|---|
| A | 스토리보드(9장 표 + 확인이 필요한 부분) | 사용자 승인 |
| B | 웹툰 이미지 프롬프트 + 실사/자료 카드에 쓸 사진·자료 목록 | 사람이 이미지 생성·수집 |
| C | 합성 지시서(카드별 배치·문구·색) | 사람이 캔바 등에서 제작 |
| D | 완성 PNG 점검(체크리스트) | 수정 요청 반영 |
| E | 채널별 캡션(인스타그램 먼저) | 승인 후 페이스북 등 나머지 |

**인스타그램 버전을 먼저 만들어 확인받고, 동의한 뒤에 페이스북 등 다른 채널 버전을 만든다.**
사용자가 "스토리보드만" 처럼 범위를 좁히면 그 범위까지만 한다.

## 2. 스토리보드 작성 규칙 (단계 A)

- 규격: 1080×1350(4:5). 분량 9~10장. 인스타그램 캐러셀은 **최대 10장**이다.
- 구성 순서: 표지(궁금증 유발) → 반전/문제제기 → 데이터 1~2개 → 비교·차트 → 세부데이터/근거 → 해결책 → 체크리스트/인용 → CTA·클로징.
- **표지(1번)**: 5~8단어 내외 헤드라인, 정보를 절반만 공개하는 궁금증 유발형. 인스타 캐러셀 썸네일이라 문구가 잘리면 안 된다.
- **마지막 카드(CTA)**: 무료 상담 같은 **다음 행동 한 가지**만 제시한다. 이미지 안에는 실제 URL을 넣지 않는다(URL은 캡션에 전체 주소로).
- **원문 반영 원칙**: 블로그의 소제목 순서·핵심 문장·수치를 그대로 따른다. 원문과 괴리된 카드를 만들지 않는다.
- **하단 안전 여백**: 모든 글자·배너·화살표는 y≈1170px 위에 둔다(하단 약 180px 비움). 앱의 하단 메뉴·캐러셀 표시·캡션 UI에 가려지기 때문이다.
- 표 형식: `# | 카드 | 블로그 대응 | 화면 텍스트(강조는 **볼드**)`. 카드마다 "블로그의 어느 부분인지"를 반드시 적는다.
- 문서 맨 위 메타 정보: 출처 원고, 규격, 장수, 톤, 쓸 수 있는 실제 사진, 텍스트 가독성 메모.
- 문서 맨 아래에 **"확인이 필요한 부분"** 섹션을 반드시 둔다. 원고에 없는 내용을 줄이거나 해석한 지점, 사람의 발언을 요약해 인용한 지점을 모두 밝힌다.
- 수치 카드는 **출처와 한계**를 같은 카드에 넣는다(예: "서로 다른 시험·집단의 수치"). 한계를 생략해야 하면 "확인이 필요한 부분"에 적는다.
- 예시는 `references/예시_스토리보드.md`를 본다.

### 기본 형식: 웹툰 × 실사 하이브리드

- **서사는 웹툰, 증거는 실사.** 9장 중 표지(1)·반전(2)·해결책(6)·인용구(7 또는 8)·CTA(9) 5장은 웹툰 일러스트, 데이터·근거·결과 4장은 실제 자료·사진이다.
- 성적표·오답노트·통계표 같은 **진짜 증거는 일러스트로 바꾸지 않는다**(신뢰 신호).
- 실사 사진이 9장 미만이면 9장을 전부 실사로 채우지 않는다. 같은 사진을 크롭만 바꿔 반복하면 캐러셀에서 티가 난다.
  사진이 충분히(9장 이상) 있고 사용자가 실사 위주를 원할 때만 전체 실사로 만든다.

## 3. 이미지 프롬프트 작성 규칙 (단계 B)

이 스킬은 이미지를 직접 만들지 않는다. 사용자가 구글 플로우·Gemini·미드저니 등에 붙여 넣을 **프롬프트**를 쓴다.
양식은 `references/이미지프롬프트_양식.md`.

- 모든 프롬프트에 **공통 스타일 문구**를 그대로 넣는다(브랜드설정의 "일러스트 스타일" 항목).
- 화면 안에 **글자·숫자·로고를 넣지 않는다.** AI가 만든 글자는 깨진다. 글자는 전부 합성 단계에서 얹는다.
  시험지·성적표·노트의 글자·숫자는 "읽을 수 없는 흐린 선"으로만 그리게 한다.
- **의상·외모 고정 문구**를 매 프롬프트에 반복해 넣는다(같은 인물이 컷마다 달라지는 것을 막는다). 특정 학교 교복·로고 금지.
- 비율은 3:4 세로로 생성해도 된다(합성 때 4:5로 크롭). **인물을 프레임 가장자리에 붙이지 않는다.**
- **화면 하단 35%는 책상·벽 같은 단순한 면으로 비운다** — 그 자리에 헤드라인이 들어간다.
- 카드마다 "장면 / 인물 표정 / 소품 / 배경 / 저장 파일명(card01.png)"을 쓴다.
- 실제 사람 사진(학생·학부모)은 얼굴이 식별되면 **모자이크 후** 사용한다. 원본은 "(비공개)"로 구분해 보관한다.

## 4. 합성 지시서 작성 규칙 (단계 C)

사람이 캔바·파워포인트에서 만들 수 있도록 카드별로 아래를 적는다.

- 캔버스 1080×1350px, 배경 이미지 풀블리드(프레임·테두리 없음).
- **팔레트는 브랜드설정의 2~3색만** 쓴다. 그 외 색상 금지(예시 브랜드는 남색 #10203f + 골드 #F0B93D + 흰색).
- 폰트는 브랜드설정의 한 가지 계열(굵기만 달리해 제목 Bold / 본문 Regular).
- 하단 그라데이션: 이미지 위쪽 40~50%는 원본 그대로 밝게, 아래로 갈수록 짙은 브랜드색으로 어두워지게 깔아 흰 글자 대비를 확보한다.
- 헤드라인: 흰색 굵은 글자 2~3줄, **핵심 키워드 한 곳만** 강조색(골드)으로. 모든 글자는 y≈1170px 위.
- 우측 상단에 페이지 카운터 `0X / 09`. 로고는 좌측 상단에 작게(일관된 위치).
- 한 줄이 너무 길면 단어 단위로 줄바꿈한다(단어 중간에서 끊기지 않게). 헤드라인이 잘리지 않는지 마지막 줄까지 확인한다.
- 중반 CTA 배너(선택): 데이터 카드 직후에 1회 작게. 마지막 카드(CTA)는 가장 크게.

## 5. 온스크린 CTA 문구 (카드 안에 들어가는 글)

CTA는 **채널별로 다른 파일**을 만든다. 같은 이미지를 여러 채널에 공유하지 않는다. 브랜드설정의 "CTA 방식"에 따라 고른다.

- 인스타그램(댓글→DM 자동응답을 설정한 경우만): "댓글에 '숫자' 남겨주세요. 학원 정보와 무료상담 링크를 보내드려요."
  - 이 키워드는 **인스타그램 전용**이다. 자동응답이 없는 다른 채널(카카오톡채널 등)에서 같은 키워드를 쓰면, 존재하지 않는 자동응답이 있는 것처럼 오해시킨다.
  - 자동응답을 설정하지 않았다면 이 문구를 쓰지 않고, "프로필 링크에서 확인하세요" 등 실제로 가능한 행동만 쓴다.
- 페이스북: "더보기란에 무료상담 링크, 학원 정보 링크가 있어요." (캡션이 짧은 노출 구간 안에 링크를 두어야 문구와 일치)
- 반자동·수동 채널(당근·카카오톡채널·네이버플레이스 등): 온스크린 CTA 배너를 넣지 않은 버전(CTA 없는 마무리 카드)을 쓴다.
- **한 카드·한 게시물에는 행동 하나만** 요구한다. 근거 없는 긴급성(가짜 선착순·마감임박)은 금지.
- 문구가 가리키는 대상이 실제로 있어야 한다(더보기 안에 링크가 있는지, 자동응답이 켜져 있는지 발행 전 확인).

## 6. 채널별 캡션 (단계 E)

채널마다 **별도로** 쓴다(공용 캡션을 그대로 붙여 넣지 않는다). 글자수는 반드시 실제로 세어 한도 안인지 확인한다.

| 채널 | 한도 | 클릭 전 노출 구간 |
|---|---|---|
| 인스타그램(카드뉴스) | 2,200자 | 약 125자 — 후킹 + 데이터 1개 |
| 페이스북 | 사실상 무제한 | 약 3줄(90~110자) |
| 당근마켓 | 500자 미만 | 목록 1~2줄 |
| 카카오톡채널 | 제한 없음 | 목록 1~2줄 |
| 네이버플레이스 | 제목 40자 / 설명 1000자 | 제목 전체, 설명 1줄 |
| 스레드 | 500자 | 대부분 노출 |

**마스터 구조(인스타그램 기준, 다른 채널은 변형)**
① 후킹 질문/문장 → ② 반전 유도 → ③ 데이터 포인트 2~3개 → ④ 인사이트 1~2문장 →
**⑤ "📝 원문 보기 👉 [블로그 글 주소]" (후킹+핵심 요약 바로 아래)** → ⑥ 행동 제안 → ⑦ 연락처 블록(브랜드설정 순서 그대로) → ⑧ 해시태그 8~12개

**서식 규칙**
- ①②③ 같은 리스트·체크리스트는 **항목마다 줄을 바꾸고** 앞뒤로 빈 줄 한 줄.
- 링크는 라벨 줄 바로 아래 줄에 URL만 단독으로 둔다. 항목 사이에는 빈 줄.
  **예외: 손가락 이모지(👉)가 있는 줄은 URL을 이모지 바로 옆(같은 줄)에 둔다.**
- 연락처 블록은 묶음끼리 빈 줄로 구분한다(홈페이지 / 상담 채널 / 블로그·지도 / 전화·주소 / 저장 유도).
- 원문 링크는 항상 **독자가 아는 대표 블로그 글 주소**다. 글 주소를 모르면 `{{BLOG_URL}}`로 두고 발행 직전에 사용자가 채운다.
- 인스타그램 캡션에는 "더보기를 눌러 확인하세요" 문구를 넣지 않는다(이미 더보기를 눌러 읽는 중이므로 모순). 페이스북은 노출 구간 안에 두므로 유지.
- 해시태그: 브랜드설정의 **동네 단위 태그 + 타겟 학교 태그 전체**를 반드시 포함한다. 시·도 단위로 넓은 태그는 쓰지 않는다.
- 작성자용 메모(글자수 확인, 레이아웃 안내)는 **`[※ ... ]`** 형식으로만 쓴다. 그 외 괄호는 게시물에 그대로 올라간다. 최종 게시본에서는 모두 지운다.
- **법정 고시사항**(학원법 등록번호·교습비 등 브랜드설정에 있는 것)은 연락처 블록 맨 아래에 반드시 넣는다.
- 네이버플레이스 캡션에는 리뷰를 유도하는 문구를 넣지 않는다.

## 7. 네이버플레이스용 카드 5장 (선택)

플레이스 소식은 사진 수 제한 때문에 9장을 다 올릴 수 없다. **CTA 없는 반자동용 9장**에서 5장을 골라 따로 묶는다.
선택 기준: 표지 → 핵심 데이터 1~2장 → 체크리스트(또는 해결책) → CTA 없는 마무리 카드. 원본 번호 대응표를 같이 적는다.

## 8. 안전·법규 원칙 (모든 단계)

- 학생 얼굴·실명·성적표·수험번호 등 개인 식별 정보는 카드·캡션 어디에도 노출하지 않는다. 후기는 "오OO" 식으로 익명화.
- 결과를 보장하는 표현("반드시 올라요", "100% 합격")·근거 없는 최상급·타 학원 비교는 쓰지 않는다. 사례를 쓸 때는 "학생마다 결과는 다를 수 있습니다"를 함께 둔다.
- 외부 통계·기사를 인용할 때는 **출처(기관·날짜)와 한계**를 함께 쓴다. 출처를 확인하지 못한 수치는 쓰지 않고 `[확인 필요]`로 표시한다.
- 사람의 말을 요약해 따옴표로 인용할 때는 당사자 확인이 필요하다고 "확인이 필요한 부분"에 쓴다.
- 광고·표시 관련 법규(학원법, 표시광고법 등)는 이 스킬이 대신 판정하지 않는다. 애매하면 사용자에게 확인을 요청한다.

## 9. 단계 D — 완성 PNG 점검 체크리스트

사용자가 이미지를 올리면 카드마다 아래를 확인하고 문제를 번호로 알려 준다.

- [ ] 1080×1350인가? 9장(최대 10장)인가? 순서가 스토리보드와 같은가?
- [ ] 모든 글자가 y≈1170px 위에 있는가(하단 여백에 밝은 글자 픽셀 없음)?
- [ ] 헤드라인이 잘리지 않았나? 단어 중간에서 줄이 끊기지 않았나?
- [ ] 글자 대비가 충분한가(밝은 배경 위 흰 글자 주의)?
- [ ] 색상이 팔레트 안인가? 폰트가 한 계열인가? 강조색이 한 곳뿐인가?
- [ ] AI 이미지 안에 깨진 글자·숫자·로고가 남아 있지 않은가? 생성 도구 워터마크가 지워졌는가?
- [ ] 인물 외모·의상이 컷마다 일관된가? 손가락·눈 같은 AI 오류가 없는가?
- [ ] 수치·출처가 원고와 같은가? 한계 문구가 있는가?
- [ ] 채널별 CTA 문구가 올바른 파일에 들어갔나(인스타 키워드 문구가 페이스북 파일에 없나)?
- [ ] 마지막 카드에 행동이 한 가지뿐인가? URL이 이미지 안에 없는가?
