# 카드뉴스 제작 워크플로우 (Claude 프로젝트 + 외부 도구)

Claude Code 없이 claude.ai의 **프로젝트**에서 진행하는 방법입니다. Claude는 글·지시서·프롬프트·캡션·점검을 맡고,
이미지 생성과 글자 합성은 사람이 외부 도구에서 합니다.

## 준비물

| 용도 | 도구 | 비고 |
|---|---|---|
| 기획·글·점검 | claude.ai 프로젝트 | 스킬 파일 + 브랜드설정을 넣어 둠 |
| 웹툰 이미지 생성 | 구글 플로우(Flow) / Gemini / 미드저니 등 | 한 가지로 통일해야 인물이 일관됨 |
| 글자 합성 | 캔바(Canva) 또는 파워포인트 | 1080×1350 템플릿을 한 번 만들어 재사용 |
| 발행 | 인스타그램·페이스북·당근·카카오톡채널·네이버플레이스 앱/관리자 | 수동 업로드 |

## 한 번만 하는 설정 (약 30분)

1. claude.ai에서 **새 프로젝트**를 만든다(이름 예: 카드뉴스 제작).
2. **프로젝트 지침**에 `프로젝트_지침.md` 내용을 붙여 넣는다.
3. **프로젝트 지식(파일)** 에 `card-news-production` 폴더의 파일을 올린다: `SKILL.md`와 `references/` 안 4개 파일.
   (스킬 업로드를 지원하는 요금제라면 `card-news-production.zip`을 스킬로 올려도 된다 — README 참고.)
4. `references/브랜드설정.md`의 `[여기에 입력]` 칸을 모두 채워 다시 올린다(프로젝트 지식의 기존 파일은 교체).
5. 캔바에서 **1080×1350px** 새 디자인을 만들고 카드 한 장 템플릿을 만든다:
   - 배경 이미지 자리(전체 채움) + 하단 그라데이션(투명 → 브랜드 짙은색, 아래쪽 약 45%)
   - 헤드라인 글상자(흰색, Bold, y 1170 위), 강조 단어용 색상 한 가지
   - 우측 상단 페이지 카운터 `01 / 09`, 좌측 상단 로고
   - 이 한 장을 복제해 9장으로 쓴다.

## 주간 사이클 (카드뉴스 1세트)

### 1단계. 원고 넣기 (Claude)
프로젝트 새 대화에서 블로그 원고 전체와 아래를 같이 보낸다.

```
이번 주 카드뉴스를 만들자. 아래가 출처 블로그 원고야. 카드뉴스 스킬 순서대로 진행하고,
먼저 스토리보드(단계 A)만 써줘. 타겟은 [브랜드설정의 타겟]으로 확인했어.
[원고 붙여넣기]
```

Claude가 `카드뉴스_스토리보드.md`(9장 표 + "확인이 필요한 부분")를 만든다.
**확인 포인트**: 표지 문구, 수치·출처, 사람 발언을 줄인 인용문, 원고에 없는 내용이 들어갔는지.
수정 요청은 같은 대화에서 "3번 카드 문구를 …로 바꿔줘" 식으로 한다. 승인되면 "승인, 다음 단계"라고 말한다.

### 2단계. 이미지 프롬프트 받기 (Claude → 사람)
```
승인. 단계 B로 가자. 웹툰 카드 5장의 이미지 프롬프트를 이미지프롬프트_양식대로 써주고,
실사·자료 카드에 필요한 사진/자료 목록도 정리해줘.
```
- 프롬프트를 카드 번호별로 복사해 이미지 생성 도구에 붙여 넣고, `card01.png`처럼 번호로 저장한다.
- 같은 인물이 필요한 카드는 **한 대화/한 프로젝트 안에서** 만든다(외모 일관성).
- 실사 카드: 학원 사진·자료를 준비한다. 학생 얼굴은 모자이크, 성적표·수험번호 등은 가린다.

### 3단계. 합성 지시서 받기 (Claude)
```
이미지 준비됐어. 단계 C: 카드 9장 각각 합성 지시서(배치·문구·강조 단어)를 써줘.
```
- 지시서대로 캔바 템플릿에 이미지를 넣고 문구를 입력한다. 인스타그램용 9장을 먼저 `instagram/01~09.png`로 내려받는다.
- 우하단 생성도구 워터마크는 그라데이션이나 크롭으로 가린다.

### 4단계. 완성본 점검 (Claude)
완성 PNG 9장을 대화에 올리고:
```
단계 D. 완성 카드뉴스 9장이야. SKILL의 점검 체크리스트대로 카드별로 문제를 번호로 알려줘.
```
지적받은 카드만 고쳐 다시 올린다. 문제가 없을 때까지 반복한다.

### 5단계. 인스타그램 확인 후 페이스북 버전
인스타그램 버전이 확정되면 마지막 카드의 CTA 문구만 채널용으로 바꿔 `facebook/01~09.png`를 만든다.
채널 CTA 문구는 SKILL §5 규칙을 따른다. 반자동 채널(당근·카카오톡채널·네이버플레이스)용은 **CTA 배너가 없는 마무리 카드** 버전을 쓴다.

### 6단계. 캡션 받기 (Claude)
```
단계 E. 인스타그램 캡션부터 써줘. 블로그 글 주소는 [주소]야. 글자수도 실제로 세서 알려줘.
```
확정되면 "페이스북, 당근마켓, 카카오톡채널, 네이버플레이스 캡션도 써줘"로 이어간다.
플레이스 5장이 필요하면 "CTA 없는 9장 중 네이버플레이스용 5장을 골라줘"라고 한다.

### 7단계. 발행 직전 점검 (사람)
- [ ] 캡션의 `[※ …]` 메모와 `{{BLOG_URL}}` 자리표시자를 모두 지웠다/채웠다.
- [ ] 연락처·법정 고시사항이 브랜드설정과 같다.
- [ ] (인스타 댓글 키워드를 쓰는 경우) 댓글→DM 자동응답이 실제로 켜져 있고, 적용 게시물이 "전체"로 돼 있다.
- [ ] AI로 만든 이미지임을 표시하는 플랫폼 옵션이 있으면 켰다.
- [ ] 이미지 순서가 맞고 9장(최대 10장)이다.

### 8단계. 발행·기록 (사람)
- 인스타그램·페이스북·당근마켓·카카오톡채널·네이버플레이스에 직접 업로드한다.
- 발행일·채널을 간단히 기록해 둔다(스프레드시트 한 줄이면 충분).

## 요일 배치 예시 (참고)

블로그 발행 다음 날 카드뉴스를 올리는 식으로 한 주를 짠다. 정해진 요일이 없다면 이렇게 시작해 본다.

| 요일 | 할 일 |
|---|---|
| 월 | 블로그 원고 확정 → 1단계(스토리보드) |
| 화 | 2~3단계(이미지·합성) |
| 수 | 4~6단계(점검·캡션) → 발행 |

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| Claude가 브랜드 정보를 묻는다 | `브랜드설정.md`에 `[여기에 입력]`이 남아 있다. 채워서 프로젝트 지식을 교체한다. |
| 인물이 컷마다 다르게 나온다 | 인물 고정 설명을 매 프롬프트에 그대로 반복하고, 같은 도구·같은 대화에서 생성한다. |
| 이미지 안 글자가 깨진다 | 프롬프트에 "글자·숫자·로고 없음"을 유지하고, 글자는 캔바에서 얹는다. |
| 헤드라인이 아래 메뉴에 가려진다 | y≈1170px 위로 올리고 점검 체크리스트를 다시 확인한다. |
| 캡션이 한도를 넘는다 | 링크를 줄이지 말고 본문을 줄인다. Claude에게 "한도 안으로 줄여줘"라고 요청한다. |
| 대화가 너무 길어졌다 | 새 대화를 열고 스토리보드·캡션 파일 내용만 붙여 넣어 이어간다(프로젝트 지식은 유지됨). |

## 이 워크플로우에서 빠진 것

- 영상(숏츠·릴스) 제작과 자동 발행은 이 문서의 범위가 아니다. 카드뉴스는 직접 업로드한다.
- 이미지 합성을 사람이 하는 대신, 템플릿을 한 번 만들어 두면 카드당 5분 안팎으로 줄일 수 있다.
