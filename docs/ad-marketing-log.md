## 운영 원칙

- 최소 4주(28일) 간격, 또는 사용자가 "광고 지식 업데이트해줘" 등으로 명시 요청 시
  재조사한다(algorithm-searching-team과 동일 주기 원칙).
- 조사 결과가 `docs/ad-marketing-knowledge.md`의 기존 내용과 달라지면 해당 절을
  갱신하고, 바뀐 게 없으면 "변경 없음"으로 이 표에만 기록한다.
- `content-playbook.md`의 규칙을 실제로 바꿔야 한다고 판단되면 algorithm-searching-team과
  동일하게 **PR로 제안**하고 사용자 승인 후에만 반영한다 — mainmanager가 임의로
  content-playbook.md를 수정하지 않는다.
