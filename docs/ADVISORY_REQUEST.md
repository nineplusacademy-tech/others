# ChatGPT 자문 요청서 표준 양식

사용법: 아래 양식을 복사해 새 요청서를 쓴다. 요청서는 **실제 구현 상태**를 기준으로 쓰고, 추측과 불필요한 설명은 넣지 않는다. 전달 전에 [`CHATGPT_ADVISORY.md`](CHATGPT_ADVISORY.md) §5(금지 정보)를 점검한다. 작성한 요청서는 저장소에 올리지 않고 로컬 `C:\Users\user\Desktop\cross-review\`에 `advisory_NNN_<주제>.md`로 둔다. 이 파일은 양식만 담는다.

---

## 요청서 양식

```markdown
# 자문 요청서 NNN: <주제>
- 작성일:
- 작성자: Claude Code
- 요청 유형: (설계 전 / 구조 결정 / 구조 변경 / 디자인·UX / 마케팅·콘텐츠 전략 / 문제 해결 / 기능 완성 / 결과물 품질)
- 프로젝트 배경(2~3줄): 나인플러스학원 마케팅 자동화. Claude Code가 실행, ChatGPT는 독립 자문, 사용자가 최종 결정.

## 1. 현재 작업의 목적
(무엇을 이루려는지, 왜 지금 필요한지, 성공 기준)

## 2. 현재까지 진행한 내용
(날짜순 요약. 완료·진행 중·보류를 구분)

## 3. 구현된 기능과 변경된 파일
| 기능 | 상태(완료/부분/미구현) | 파일 경로 |
|---|---|---|

변경된 파일 목록과 변경 요지:

## 4. 현재 구현 방식과 기술적 선택
- 방식:
- 선택한 이유와 버린 대안:
- 핵심 코드 또는 설정(필요한 부분만, 비밀값 제외):
- 실행 결과·로그·오류 메시지(원문):

## 5. 해결되지 않은 문제
(재현 방법, 원인 가설과 확인 여부, 시도한 해결책과 결과)

## 6. Claude Code가 판단한 최선의 방향
(권장안, 근거, 예상 효과와 위험, 변경 범위)

## 7. ChatGPT에게 검토받고 싶은 사항
1.
2.
3.
(질문은 구체적으로. "대체 방안", "더 나은 구조", "놓친 위험" 같은 열린 질문도 포함)

## 8. 관련 파일 및 참고 자료
- 파일:
- 문서:
- 외부 자료(주소·확인일):

## 출력 형식 요청
항목마다 `[우선순위: 높음/중간/낮음] 제안 — 근거 — 기대 효과 — 변경 범위 — 위험`. 확인할 수 없는 사실은 "확인 불가"로 표시하고 추측하지 않는다. 칭찬·군더더기 금지. 현재 방향보다 나은 대안이 있으면 먼저 말한다.
```

## 작성 체크리스트

- [ ] 목적과 질문이 요청서만 읽고 이해되는가
- [ ] 구현 상태가 추측이 아니라 실제 파일·로그 기준인가
- [ ] 비밀값·개인정보·연락처를 뺐는가
- [ ] 이미 내린 의사결정과 그 이유가 적혀 있는가(맥락 유지)
- [ ] 사소한 수정이 아니라 외부 검토가 도움이 되는 사안인가
