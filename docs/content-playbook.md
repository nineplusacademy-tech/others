## 2. 블로그 원고 작성 규칙

### 3단계 진행 순서

1. **1단계**: 기획안 추천(오늘 날짜·시즌 고려해 3개 추천, 사용자가 1개 선택)
2. **2단계**: 원고 작성 + 사진 요청 (한 번에 여러 장 요구하지 않고 하나씩)
3. **3단계**: 이미지 제작

### 원고 작성 규칙 10가지

1. 제목에 핵심키워드 포함 + 클릭하고 싶게
2. 첫 3줄에서 학부모 고민에 공감하며 끝까지 읽게
3. 소제목(H2) 4~5개, 본문에 키워드 3~5회 자연스럽게
4. 충분한 정보 제공 후 마지막에 부담 없는 상담 안내
5. 과장·허위 표현 금지, 친절한 설명체, 2500자 내외
6. 네이버 C-RANK·SEO 반영 + AI 검색노출(GEO/AEO) 규칙(아래 절 참고) 함께 반영
7. 필요한 사진이 없으면 같은 팔레트(남색+골드+흰색) 톤의 일러스트 생성 프롬프트를
   제시해 사용자가 직접 AI 이미지 도구로 만들도록 한다(임의로 일러스트를 대체 제작하지
   않음). 프롬프트 작성 기준:
   - 프롬프트는 반드시 한국어로 작성 (영어 프롬프트는 인물이 외국인 외모로 나오는
     문제가 반복 확인됨)
   - 스타일: "고퀄리티 한국 웹툰 스타일 일러스트, 깔끔한 선화(라인아트) + 부드러운
     셀 셰이딩", 색감은 남색+골드 포인트
   - 인물 등장 시 "검은 머리에 동양인 이목구비를 가진 한국 OO학생"처럼 눈에 보이는
     특징을 구체적으로 명시(인물마다 빠짐없이)
   - "photorealistic" 등 사진 촬영 스타일 표현은 넣지 않음
8. 원고 마지막에 연락처 블록(3절 참고) + 해시태그 8~12개 반드시 포함. 홍보형(P) 원고는
   "관련 학교" 6개(동성중학교(수원)·동수원중학교·산남중학교·유신고등학교·창현고등학교·
   광교고등학교)를 절대 축약하지 않고 항상 전부 표기. 정보형(I/L/M)은 글 내용에 맞게
   조정 가능.
9. 사진 위치 표시: 본문 안에 `[📷 사진 자리 N · 대표이미지/본문이미지 N — 비율]` 형식으로
   표시하고, 같은 폴더에 `사진요청_및_일러스트프롬프트.md` 파일을 만들어 자리별 필요한
   사진과 대체 일러스트 프롬프트를 정리한다(D.I.A.+ 가점 기준 — 가능하면 실제 사진 6장
   이상).
   - 구글 블로그(Blogger) 호환용 사본 `구글블로그용.md`도 함께 작성 — 실제 HTML 태그
     (`<h2>` `<p>` `<strong>` `<a href>` `<img src alt=...>`)로 작성하되, **제목·라벨·
     검색 설명은 반드시 파일 맨 위 YAML 프런트매터로 작성한다**(`publishing-plan.md`
     "각 파일의 정확한 형식" 참고 — `title:`·`labels: [...]`·`search_description:`
     세 필드). 본문 중간에 HTML 주석으로만 적어두면 발행 스크립트가 읽지 못해 검색
     설명·라벨·제목이 빈 채로 그대로 게시된다(2026-09-08 36주차 실사고로 확인된 문제
     — 반드시 프런트매터 필드로). **라벨은 SEO 태그가 아니라 블로그 상단 메뉴
     카테고리다** — 블로그 네비게이션이 `교육뉴스`·`학습법`·`학원소식`·`합격후기`
     4개 라벨 기반으로 구성돼 있으므로, `labels:`에는 이 중 그 글에 맞는 **정확히
     1개만** 넣는다(2026-09-08 확인 — 예전에 여기 있던 "라벨(8~12개)" 지침은 오류였고,
     그 개수는 원고 마지막의 SNS용 해시태그(§2-8, §8 채널별 캡션)에만 해당).
   - 유튜브 커뮤니티 게시물 사본 `유튜브_게시물.md`도 함께 작성 — 실제 노출 구간은 첫
     100~125자이므로 그 안에 후킹+핵심데이터 압축, 전체 300~600자 권장. 이미지 최대
     10장(최소 1080x1080). 댓글DM 미지원 채널이므로 카카오톡채널·네이버톡톡·블로그
     링크를 텍스트에 그대로 노출.
10. 네이버 블로그 호환용 사본 `블로그용.txt`도 함께 작성(마크다운 기호 제거, H2→▶
    소제목, 목록→• 로 변환).

### AI 검색노출(AEO/GEO) 대응 규칙

- 네이버 AI 브리핑은 정보형(원인·이유·방법형) 질의에서만 노출을 활성화하므로, 전환형
  제목 글이라도 본문 중간에 "왜 ~한가요" 형태의 정보형 소제목(H3) 1개를 끼워 넣는다.
- 도입부(공감 3줄) 다음에 핵심 질문에 대한 즉답 1~2문장을 서론 없이 배치.
- 소제목 1~2개는 학부모가 실제 검색할 법한 질문 그대로(FAQ형)로 작성.
- 통계 인용 시 "약 30%" 대신 "29.2%"처럼 구체적 수치+출처 명시.
- H2/H3 구조를 명확히 유지 — 구조화된 문서일수록 AI가 특정 문단만 발췌·인용하기 쉬움.

## 10. 댓글→DM 자동 응답 (KittyChat)

- 적용 범위: 인스타그램 + 페이스북(메타 계열)만 가능. 메타는 공식 API로 댓글→DM/
  Messenger 자동화를 지원.
- 유튜브·틱톡·링크드인은 크리에이터→시청자 개인 메시지를 보낼 공식 API 자체가 없어
  동일한 자동 DM 구현이 원천적으로 불가능(어떤 툴을 써도 동일). → 유튜브는 대신 "고정
  댓글"(업로드 직후 채널 소유자가 상담 링크 3종을 댓글로 남기고 우측 "..." 메뉴에서
  고정, 무료·수동, 채널당 1회 클릭) + 설명란 상단 CTA 문구로 대체.
- 사용 툴: KittyChat(kittychat.ai) — Meta 공식 Messaging API 기반 승인 서비스, 계정
  연결 완료(2026-08-28). 무료 플랜 월 500건, 결제정보 불요.
  - 참고: KittyChat은 독립 리뷰(G2·Trustpilot)는 거의 없는 소규모 서비스지만, 캐나다
    법인(Peerprinter Inc.) 운영에 실사용 후기(팔로워 수십만 계정 포함)가 다수 확인됨.
    ManyChat은 2026년 3월부터 무료 플랜이 월 25명으로 축소되어 사실상 유료화, InstantDM은
    G2 평점 4.3·월 9.99달러 정액 무제한이라는 대안도 있음(필요시 전환 검토 가능).
- 정책 안전성: "상대가 먼저 댓글을 남긴 경우"에만 반응 + 24시간 내 완결 = 계정 정지
  위험 없음. 콜드DM·자동팔로우는 절대 사용 금지.
- 설정: 키워드 "9" 등록(매칭은 "특정"=정확히 일치로 설정, 오탐 방지) + DM 템플릿 등록
  (6개 학교 언급 + 카카오톡·네이버톡톡·블로그 링크) + "게시물 선택"에서 대상 게시물
  지정(다음 발행되는 게시물에 자동 적용되는지, 매번 수동 재선택이 필요한지는 실제
  발행 후 재확인 필요).
- 운영: 발행 전 KittyChat 대시보드에서 자동화가 실제로 켜져 있는지, 월 발송 건수
  (무료 한도 500건)를 매번 확인한다.

카드뉴스·숏츠 모두 **채널마다 온스크린 CTA 문구가 다르므로**(§7) 2026-09-08부터
인스타그램·페이스북(·유튜브)용을 각각 별도 HyperFrames 프로젝트로 렌더링한다 —

HyperFrames 렌더링용 소스 프로젝트(디버그 이미지 등)는 `카드뉴스(또는 숏츠)/_원본프로젝트/`

## 12. 개인정보·안전 원칙

- 실제 학생 얼굴·실명이 담긴 사진·스크린샷은 반드시 모자이크(픽셀化) 처리 후에만 게시용
  으로 사용. 원본은 "(비공개)" 표기로 구분해 보관하고 게시에는 사용하지 않는다.
- 학생 후기 인용 시 실명 대신 "OOO" 또는 "오OO" 형태로 익명화.
- 성적표·수험번호 등 구체적 개인 식별정보는 원고·이미지 어디에도 노출하지 않는다(이미
  홈페이지에 공개된 "○명 합격" 수준의 익명 정보만 인용).
- 네이버플레이스: 리뷰를 유도하는 문구는 절대 넣지 않는다 — 특정 시점에 리뷰·클릭이
  몰리면 비정상 패턴으로 감지돼 노출이 제한될 수 있다.
