<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">3. 올해 가장 눈에 띄는 변화: 스마트안경</h2>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">평가원은 10월 15일 '2027학년도 대학수학능력시험 수험생 유의사항'과 관련 영상을 홈페이지에 게시했고, 연합뉴스는 이 내용을 이렇게 전했습니다.</p>

<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">감독관은 수험생 본인 여부 확인, 휴대 가능 시계 확인, 시험 시간 등을 활용해 스마트안경을 관찰하고 확인을 요청할 수 있습니다. 확인을 요청받으면 수험생은 안경을 벗어 책상 위에 놓고 감독관의 확인과 점검에 협조해야 합니다.</p>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">이런 강한 규정이 나온 배경으로 연합뉴스는 올해 5월 토익 정기시험에서 스마트안경을 쓴 응시자가 부정행위로 처리된 일, 10월 3일 서울시립대와 10월 10일 연세대 논술시험에서 스마트안경을 쓴 수험생이 적발된 일을 들었습니다. 한편 교사 단체는 감독관의 확인 업무 부담이 커진다고 지적했습니다. 다만 일반 안경을 착용하는 것 자체를 금지한다는 내용은 이 보도에 나와 있지 않습니다. 본인 안경이 스마트안경인지 헷갈리는 경우에는 시험 전에 제조사 안내나 학교·시·도교육청에 문의해 확인해 두시는 것이 안전합니다.</p>
<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">4. 시험장 반입 금지 물품과 휴대 가능 물품</h2>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">평가원 안내의 핵심은 '시험 중 활용 여부와 기능에 관계없이 모든 전자기기는 원칙적으로 시험장 반입이 금지된다'는 것입니다.</p>

<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">반입 금지 물품을 불가피하게 가져온 경우에는 1교시 시작 전에 감독관의 지시에 따라 제출해야 하고(미제출 시 부정행위로 간주), 응시하는 모든 영역·과목의 시험이 끝난 뒤 돌려받습니다. 신체 조건이나 의료상 필요한 물품(돋보기, 보청기, 인공와우, 혈당관리기기, 귀마개, 방석 등)은 매 교시 감독관의 사전 점검을 거쳐 휴대할 수 있습니다.</p>
<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">5. 가채점표</h2>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">올해 수능부터 수험표 뒷면에 가채점표가 인쇄됩니다. 교육부 시행세부계획 공고에 따르면 필요한 수험생은 시험시간 안에 가채점표를 작성할 수 있습니다. 다만 매 교시 종료령 이후에 가채점표를 작성하는 것은 부정행위에 해당하므로, 종료령이 울리면 필기구를 내려놓아야 합니다.</p>
<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">6. 시험 당일 알아둘 점</h2>
<ul style="margin:0 0 16px; padding-left:22px; line-height:1.85; font-size:16px;"><li style="margin-bottom:6px;"><b>준비물</b>: 수험표, 사진이 붙은 신분증을 반드시 지참합니다. 수험표를 잃어버렸다면 입실 시간 전까지 재교부를 받아야 합니다.</li><li style="margin-bottom:6px;"><b>점심과 물</b>: 중식과 음용수는 제공되지 않습니다. 시험실에는 시계가 없으므로 휴대 가능한 시계를 미리 준비해야 합니다.</li><li style="margin-bottom:6px;"><b>필기구</b>: 시험실에서 검은색 컴퓨터용 사인펜과 샤프(흑색, 0.5mm)를 일괄 지급합니다. 수정테이프는 시험실에 5개씩 준비돼 있어 감독관에게 요청하면 쓸 수 있습니다. 본인 사인펜을 가져가는 것이 원칙입니다.</li><li style="margin-bottom:6px;"><b>본인 확인</b>: 매 교시 답안지 필적확인란에 제시된 문구를 적어야 하고, 1교시와 3교시는 시험 시작 전에 본인 확인과 휴대 가능 시계 확인 시간이 따로 있습니다.</li><li style="margin-bottom:6px;"><b>돌발 상황</b>: 시험 중 문제가 생기면 감독관의 지시에 따라 침착하게 대응하라고 안내돼 있습니다.</li></ul>
<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">7. 수능 이후 일정과 성적 확인</h2>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">수능 다음 날(11월 20일)부터 채점이 시작되고, 정답 이의신청은 시험 당일부터 11월 23일까지 받습니다. 이의신청 심사를 거친 최종 정답은 12월 1일 17:00에 발표됩니다. 성적통지표는 12월 11일(금)에 배부됩니다. 재학생은 당일 학교에서 받을 수 있고, 온라인 발급은 재학생이 14시부터, 졸업생과 검정고시 합격자는 9시부터 본인인증으로 가능합니다. 성적증명서는 같은 날 18시부터 온라인으로 발급할 수 있습니다. 영어, 한국사, 제2외국어/한문 영역은 절대평가 등급만 표기되고, 한국사 영역에 응시하지 않으면 시험 전체가 무효 처리됩니다.</p>

<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">9. 자주 묻는 질문</h2>
<h3 style="font-size:17px; margin:22px 0 8px; color:#122040;">일반 안경을 써도 되나요?</h3>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">이번 보도에는 일반 안경 착용을 금지한다는 내용이 나오지 않습니다. 감독관이 스마트안경 여부를 확인하기 위해 요청하면 안경을 벗어 책상 위에 놓고 협조해야 한다는 점이 유의사항에 담겨 있습니다.</p>
<h3 style="font-size:17px; margin:22px 0 8px; color:#122040;">시험 중에 쓸 수 있는 시계는 어떤 것인가요?</h3>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">결제·통신(블루투스 등) 기능과 전자식 화면표시기(LCD, LED)가 모두 없고, 시침·분침(초침)이 있는 아날로그 시계입니다.</p>
<h3 style="font-size:17px; margin:22px 0 8px; color:#122040;">가져온 휴대폰은 어떻게 하나요?</h3>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">반입 금지 물품을 불가피하게 가져온 경우 1교시 시작 전에 감독관의 지시에 따라 제출하고, 응시하는 모든 영역·과목의 시험이 끝난 뒤 돌려받습니다. 제출하지 않으면 부정행위로 간주합니다.</p>
<h3 style="font-size:17px; margin:22px 0 8px; color:#122040;">수능 일정이 바뀔 수도 있나요?</h3>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">평가원은 일정이 업무 사정에 따라 바뀔 수 있다고 안내합니다. 시험 직전까지 수능 홈페이지 공지와 시·도교육청 안내를 확인해 주세요.</p>
<h2 style="font-size:20px; margin:34px 0 10px; padding-left:12px; border-left:5px solid #f0b93d; color:#122040;">10. 학부모님께</h2>
<p style="margin:0 0 14px; line-height:1.85; font-size:16px; color:#122040;">수능이 가까워질수록 결과보다 당일 컨디션과 챙길 것이 마음에 걸리실 겁니다. 규정 확인은 아이가 시험에만 집중할 수 있게 도와주는 일입니다. 올해는 스마트안경처럼 처음 명시된 규정이 있으니, 아이 혼자 알아서 챙기게 두기보다 전날 가방과 준비물을 함께 한 번 훑어봐 주세요. 현재 고1·고2 학생 가정도 앞으로의 시험을 위해 이런 규정이 어떻게 달라지는지 눈여겨보시면 도움이 됩니다.</p>
