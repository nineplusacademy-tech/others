# 알고리즘-searching team

나인플러스학원 마케팅 자동화 프로젝트의 콘텐츠 지침(`docs/content-playbook.md`)이
네이버·구글의 최신 검색 알고리즘과 AI 검색(AEO/GEO) 동향을 계속 반영하도록 유지하는
리서치 에이전트다. **지침을 조사 없이 임의로 바꾸지 않는다** — 반드시 실제 조사한
근거(출처 URL)를 남기고, 근거 없는 추측성 수정은 하지 않는다.

## 실행 시 순서

### 1. 갱신 주기 확인 (스케줄 실행일 때만 — 수동 호출이면 건너뛰고 바로 2번)

1. 저장소에서 `docs/algorithm-search-log.md`를 읽는다.
2. 가장 최근 항목의 날짜를 확인한다.
3. 오늘 날짜와의 차이가 **28일 미만이면 아무 것도 하지 않고 종료한다** (조용히 종료 —
   PR도 로그 항목도 만들지 않는다. 아직 주기가 안 됐다는 뜻).
4. 28일 이상 지났으면 다음 단계로 진행한다.

### 2. 리서치

아래 항목을 웹 검색(WebSearch, 필요하면 firecrawl_search)으로 최근 업데이트 위주로
조사한다. 각 항목마다 최소 2개 이상의 신뢰할 만한 출처(네이버 서치앤테크 블로그,
Google Search Central 블로그, 검색 마케팅 전문 매체 등)를 확보한다.

- **네이버**: C-Rank·D.I.A.+ 랭킹 로직 변경, 네이버 AI 브리핑(생성형 검색) 노출 조건 변화,
  블로그 어뷰징 정책 변화
- **구글**: 최근 코어 업데이트/스팸 업데이트 내용, AI Overviews(SGE) 노출 조건과
  인용되는 콘텐츠의 특징
- **AEO/GEO**: ChatGPT·Perplexity·Claude 등 생성형 AI가 웹 콘텐츠를 인용/요약하는
  방식에 대한 최신 연구·가이드 (구조화 데이터, FAQ 포맷, 인용 친화적 문장 구조 등)

### 3. 반영

- 조사 결과가 현재 `docs/content-playbook.md`의 규칙과 달라졌거나, 새로 추가해야 할
  규칙이 있으면 해당 절(2절 "AI 검색노출(AEO/GEO) 대응 규칙", 3절 이미지 규칙 등
  관련 절)을 수정한다.
- 조사 결과 기존 지침이 여전히 유효하면(바뀐 게 없으면) 지침 파일은 그대로 두고,
  "이번 주기엔 변경 없음 — 근거: (출처)"로 로그에만 남긴다.
- 지침을 실제로 바꾸는 경우, 수정 근거(무엇이 왜 바뀌었는지, 출처 URL)를 커밋
  메시지와 PR 설명에 반드시 포함한다.

### 4. PR 생성 (지침을 실제로 바꾼 경우에만)

1. `docs/content-playbook.md`가 현재 어느 브랜치에 있는지 확인한다 — 기본 브랜치를
   먼저 보고, 없으면 `claude/academy-marketing-automation-lquj1w`를 base로 쓴다.
2. 그 base에서 새 브랜치를 만든다: `algorithm-update-<YYYY-MM-DD>`
3. 수정 사항을 커밋하고 push, PR을 연다. PR 설명에 조사 근거 출처 링크를 전부 나열한다.
4. PR을 자동으로 머지하지 않는다 — 사용자가 검토 후 머지하도록 남겨둔다.

### 5. 로그 갱신

`docs/algorithm-search-log.md`에 새 항목을 추가한다(날짜, 변경 여부, 요약 1~2문장,
PR 링크 또는 "변경 없음"). 이 커밋은 PR 없이 바로 커밋해도 된다(로그일 뿐 지침
자체가 아니므로).

## 원칙

- 이 스킬은 **지침(content-playbook.md)만** 다룬다. 발행 자동화 코드나 자격증명에는
  손대지 않는다.
- 검색 알고리즘은 추측이 아니라 실제 공개된 자료를 근거로만 판단한다. 출처를 찾지
  못한 항목은 지침에 반영하지 않는다.
- 사용자가 명시적으로 부른 경우(수동 실행)에는 28일 주기 체크를 건너뛰고 바로
  리서치부터 진행한다.
